# 珠宝选样：销售素材候选 0.1.0

运行入口：[本机工作台](http://127.0.0.1:21963)。重新打开可双击本目录 `打开素材候选.cmd`，或运行 `Start-Candidate.ps1 -Open`。独立Node/模型在D盘；启动脚本不注册开机任务。需要本地 Ollama 21434 中已有 qwen3-vl:4b，模型关闭时已上传图片进入“等待识别”，不会当首饰通过。

## 操作

1. 选文件夹或多张图片，可填来源备注，再点开始导入。每批最多300个文件，单张20MiB，支持静态JPG/PNG/WebP。原文件保持；工作台只读取本次明确选择的文件。
2. 本地解码并分类。明确首饰进入可用素材，非首饰在已跳过，不确定在待复核，服务失败在等待识别；全部可查看原因。相同原文件摘要去重，重启恢复未完成任务。
3. 输入客户描述，例如“想看简约的金色素圈戒指，不要镶嵌”。按品类、已登记标签、同义词及排除条件查找。支持供货筛选，无匹配不自动凑无关图片。陌生描述和复杂比较可能需要调整说法。
4. 核对并修正分类/标签。AI可能误判细节：公开戒指样本曾误标“珠饰”，人工观察后已更正；这不能当模型准确率通过。已跳过里也可人工纠正误判。
5. 供货默认待核实。现货/需订货/仅供参考必须人工填写依据并在确认窗提交，照片不能证明库存、材质或价格。选中素材后点客户看图，保留供货标识，隐藏文件名/来源/管理动作。

## 当前范围

这是同一台电脑的独立候选，绑定127.0.0.1，不向员工网络开放；未继承正式主系统登录/角色授权，客户看图只是本机展示模式。当前未接正式库存、员工微信扫描、F盘业务图库、云端图片服务或OpenClaw业务工具，Agent仍无软件修改/库存写入权限。后续须沿既有主系统权限链接入后再向员工开放。

本地候选已登记到 `D:/Codex/xjy-main-integration-20261023/sales-materials-integration`，源码、模型和数据仍在各独立项目。候选启动桥将调用本服务；不覆盖正式版、不改员工升级源。

`runtime/data` 存本候选JPEG副本及library.sqlite。按SQLite事务保存资产及人工修改日志；不自动清理失败图片/损坏数据库/异常journal。启动遇到未知库或校验失败会停止并保留现场，先备份整个目录再人工处理，不能直接删库。程序源码不包含图片、库、令牌和运行日志。

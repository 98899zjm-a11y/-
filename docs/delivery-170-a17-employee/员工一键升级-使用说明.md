## 二、升级前（务必按顺序）

1. **保存正在填写的单据**，确认没有未保存的报价单、单据、收付款记录。
2. 从**托盘菜单**正常退出员工端（右键托盘图标 → 退出）。不要用任务管理器强制结束。
3. 确认软件已完全退出（任务栏、托盘都没有图标）。

## 三、执行升级

4. 把整个文件夹放在**不被删除**的位置（例如桌面上的一个新建文件夹，或 D 盘专门的“升级包”目录），**不要**只把 `员工一键升级.cmd` 单独拷出来，也不要把 ZIP 解压后只拿其中几个文件。
5. 双击 **`员工一键升级.cmd`**。
6. 安装器会自动核验补丁与程序指纹，**弹出“角色确认”时选择“员工”**，然后等待它跑完（过程中会出现“正在安装及校验”的进度窗口，**不要重复双击、不要强行结束进程**）。
7. 看到**明确的完成提示**后关闭窗口。

## 四、升级后核对

8. 重新打开软件，确认能正常连接原主机、能正常开单。
9. 核对软件**右下角版本显示为 `总版本 v1.7.0`**。

## 五、三条红线

- **不要**在员工电脑上运行 `首次安装主机.cmd`（那是主机首次安装，会要求空数据目录）。
- **不要**把补丁包拆开分发（脚本要按自身目录找组件，并做固定哈希自校验，缺一个文件就会拒绝执行）。
- **不要**手工覆盖程序文件、不要删除 `.xjy-initial-upgrade` / `.xjy-patches` 目录（里面有升级前的业务数据快照）。

## 六、出问题怎么办

- 保留**原程序、升级文件夹、错误提示原文**，不要删除、不要反复重试。
- 把错误提示文字（或截图）发回来，并按提示里的英文错误码定位：
  - `NO_INSTALLATION`：没找到可核验的 1.6.2 程序位置（软件是否装在非常规目录？）
  - `UNEXPECTED_SOURCE_FILE` / `SOURCE_CHANGED`：旧程序目录里有改动过的文件
  - `UNSUPPORTED_SOURCE_VERSION`：当前已是 1.7.0，不需要再升级
  - `NATIVE_ACL_REFUSED` / `审定路径允许其他 Windows 身份…`：目录权限被策略挡下，需要维护方处理
- 升级失败时程序会保持原样，不会破坏原数据。

## 七、本次没有做到的事（如实说明）

- 员工端“软件内一键升级”**尚未在员工角色机器上做验收**（本轮只完成了主机侧真机升级）；本补丁是“完整受信补丁包 + 双击一键升级”的路径。
- 断电式失败恢复演练未执行（有恢复入口与操作手册，但没做过真实断电测试）。
- 员工补丁包**不包含主程序 shell（`鑫金源珠宝报价.exe`）**，只更新资源与业务模块，因此员工机升级后 shell 图标保持原样。

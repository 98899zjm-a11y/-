## 开发和构建条件

网页与桌面项目在 `project/`，依赖版本见相应 `package.json` 和锁文件；业务源码位于 `project/desktop/renderer`、`project/lib`、`project/desktop/legacy-source` 等目录。桌面构建入口是 `project/desktop/build.cjs`。原网页配套 `scripts/`、`build/` 和根配置从仓库现有源码补齐，仅复制维护工程缺少的文件。

此快照**不能声称可从公开源码独立重建整个正式发行版**：旧库存/内账模块部分原始实现只有供应的 `.pyc`/编译程序，没有相应 `.py` 源码。本次按项目要求不上传这些编译程序、运行依赖、生成目录、发行密钥、签名配置、正式数据库或用户配置。保留可获得的维护源码及第三方许可证，未反编译或编造缺失原始源码。原构建工具也需要既有隔离环境和外部依赖。

运行测试前先看文件开头的执行条件；部分测试强制要求原离线 Windows Sandbox、固定目录与冻结测试材料，禁止在正式主机/真实账套上直接批量执行。安装/签名脚本仅存档，发布源码不授权运行它们。

基本信息

留空的话自动按「盘点 年月日」命名。
盘点结果会跟这张表的数量比。选错批次会导致满屏虚假差异，务必确认。
填了之后本轮只盘点库位里包含这段文字的商品编号，适合分区分次盘。 多个库位用逗号隔开，例如「A区,B区」。留空 = 全盘。

打印方式

强烈建议保持勾选。纸质盘点表上印着账面数时，盘点员很容易照着抄， 盘出来的结果永远「没有差异」，盘点就白做了。
需要核对时可以在打印页临时关掉这一项。
建完之后怎么走：
  1. 在任务详情页点「打印盘点表」，用浏览器打印（或导出 Excel 再排版打印）
  2. 拿着纸去仓库数，把实盘数写在纸上
  3. 回来点「录入实盘」，用扫码枪或键盘把 商品编号 + 数量 敲进去
  4. 录完把任务状态改成「复核中」，交给复核员看差异
  5. 复核员确认后生成库存调整单，执行后账面自动更新成新的一批
